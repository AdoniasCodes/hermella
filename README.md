# Hermella Araya Manaye: Architecture Portfolio

Live: https://adoniascodes.github.io/hermella/

Vite + React 19 + TypeScript + Tailwind v4 + three.js (react-three-fiber). The home page is a
scroll-driven 3D house model that orbits, comes apart into its layers, then settles into a plan view,
followed by a 3D-tilting project gallery.

```
pnpm install
pnpm dev
pnpm build
```

Content lives in `src/data/profile.ts` and `src/data/projects.ts`.
